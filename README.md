# Bootcamp Full-Stack Web

Bootcamp de 10 semanas para estudiantes que ya tienen bases de programacion (estructuras de datos y POO en C, Java o Python) y quieren aprender a desarrollar aplicaciones web reales usando herramientas modernas y Git para trabajo colaborativo.

## Objetivo

Al finalizar, los estudiantes seran capaces de:

- Colaborar profesionalmente con Git y GitHub (branches, PRs, code review)
- Diseñar e implementar bases de datos relacionales con PostgreSQL
- Construir APIs REST con NestJS y TypeORM
- Desarrollar frontends con React y Angular que consuman APIs
- Dockerizar y desplegar aplicaciones full-stack con CI/CD
- Trabajar en equipo bajo metodologias agiles (sprints, daily standups)

## Stack tecnologico

| Capa | Tecnologias |
|---|---|
| Frontend | React, Angular, HTML, CSS, JavaScript/TypeScript |
| Backend | NestJS, Node.js, Express |
| Base de datos | PostgreSQL, TypeORM |
| DevOps | Docker, GitHub Actions, Vercel, Railway |
| Colaboracion | Git, GitHub |
