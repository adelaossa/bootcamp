# Semana 4 — React desde cero

## Objetivos de la semana

Al finalizar esta semana los estudiantes podran:

- Explicar que es React, el virtual DOM y la diferencia entre programacion declarativa e imperativa
- Crear un proyecto React con Vite + TypeScript + TailwindCSS
- Construir interfaces con componentes funcionales, props tipadas y composicion
- Manejar estado local con `useState` y efectos secundarios con `useEffect`
- Manejar eventos, formularios controlados y renderizado condicional
- Renderizar listas correctamente con keys
- Navegar entre paginas con React Router
- Consumir una API REST desde React y mostrar los datos

## Glosario

| Termino | Definicion |
|---|---|
| **React** | Libreria de JavaScript para construir interfaces de usuario |
| **JSX** | Extension de sintaxis que permite escribir HTML dentro de JavaScript |
| **Componente** | Funcion que retorna JSX. Bloque reutilizable de UI |
| **Props** | Datos que un componente padre pasa a un componente hijo |
| **Virtual DOM** | Representacion en memoria del DOM real. React lo usa para calcular cambios minimos |
| **useState** | Hook que permite agregar estado local a un componente funcional |
| **useEffect** | Hook que ejecuta efectos secundarios (fetch, timers, suscripciones) |
| **Hook** | Funcion especial que permite usar estado y otras caracteristicas de React en componentes funcionales |
| **SPA** | Single Page Application: la navegacion ocurre sin recargar la pagina completa |
| **Vite** | Build tool y dev server ultrarrápido para proyectos frontend |
| **TailwindCSS** | Framework de CSS utilitario que usa clases atomicas |
| **HMR** | Hot Module Replacement: los cambios se reflejan instantaneamente sin perder el estado |
