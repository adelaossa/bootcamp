# Semana 1 — Git, la Web y JavaScript

## Objetivos de la semana

Al finalizar esta semana los estudiantes podran:

- Explicar como funciona internet a nivel de cliente-servidor y el protocolo HTTP
- Diferenciar claramente entre frontend y backend
- Usar Git y GitHub para trabajo colaborativo (branches, PRs, code review)
- Escribir programas en JavaScript moderno (ES6+) usando Node.js
- Construir una API REST basica con Express (datos en memoria)
- Crear un frontend con HTML y CSS, usando JavaScript vanilla que consuma la API
- Entender la diferencia entre renderizado del lado del cliente (CSR) y del lado del servidor (SSR)

## Glosario

| Termino | Definicion |
|---|---|
| **API** | Interfaz de Programacion de Aplicaciones. Conjunto de endpoints que exponen funcionalidad |
| **Cliente** | El que hace la solicitud HTTP (navegador, app movil, curl) |
| **Servidor** | Programa que escucha solicitudes y responde |
| **DNS** | Traduce nombres de dominio a direcciones IP |
| **Endpoint** | URL concreta de una API (ej: `/api/productos/5`) |
| **HTTP** | Protocolo de transferencia de hipertexto (lenguaje cliente-servidor) |
| **JSON** | Formato de intercambio de datos basado en JavaScript |
| **REST** | Estilo de arquitectura para disenar APIs |
| **Express** | Framework minimalista de Node.js para construir servidores y APIs |
| **fetch** | API del navegador para hacer solicitudes HTTP desde JavaScript |
| **CORS** | Mecanismo de seguridad del navegador que restringe peticiones entre origenes |
| **Repositorio** | Carpeta con historial de Git |
| **Commit** | Punto guardado en el historial de Git |
| **Branch** | Linea independiente de desarrollo |
| **Merge** | Fusionar dos ramas |
| **PR (Pull Request)** | Solicitud para fusionar cambios, incluye code review |
| **npm** | Gestor de paquetes de Node.js |
| **package.json** | Archivo de configuracion de un proyecto Node.js |
| **async/await** | Sintaxis para manejar codigo asincrono en JavaScript |
